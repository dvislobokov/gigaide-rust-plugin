Reports a dependency of Cargo.toml whose version requirement does not allow the newest release of the crate, and offers to update it.

The newest versions are only those learned in this session, by an action of the user: Check for newer versions (cargo info, Alt+Enter on a dependency) or Tools | Rust | Check Dependency Updates (cargo update --dry-run). Cargo reaches the registry itself, through its own proxy and registry-mirror settings; the inspection never goes to the network.
